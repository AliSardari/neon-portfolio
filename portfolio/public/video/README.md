# ویدیوی پس‌زمینه‌ی هیرو

فایل‌های ویدیوی خودت را با این دو نام در همین پوشه بگذار:

- `hero.webm` (اولویت اول — حجم کمتر)
- `hero.mp4` (fallback برای مرورگرهای قدیمی‌تر)

نکات:

- ویدیو بی‌صدا باشد و حجمش را زیر ~۵ مگابایت نگه دار (هدف: ۲–۳ مگابایت).
- تا وقتی فایل‌ها اینجا نباشند، یک گرادیان متحرک بلورشده جای ویدیو نمایش داده می‌شود؛
  یعنی بدون ویدیو هم سایت ظاهر مرتبی دارد.
- بهترین حالت: کلیپ کوتاه ۱۰–۲۰ ثانیه‌ای با حرکت آرام (محیط تاریک/تکنولوژیک)
  که با پالت سرمه‌ای/آبی سایت هماهنگ باشد.
